# 🌿 Irminsul Terminal
**A Targeted Data Collation System for the Genshin Impact Community**

### **Project Mission**
The **Irminsul Terminal** is a community-driven database designed specifically for players to collate lore and environmental data from *Genshin Impact*. This project is a major milestone in my journey toward becoming a successful Computer Engineer, serving as a hands-on application of full-stack development and cloud integration.

### **Technical Evolution & AI Integration**
This project represents a modern "vibe coding" workflow—leveraging **Generative AI** as a collaborative partner to bridge the gap between academic theory and professional-grade implementation. This approach allowed for rapid prototyping, advanced troubleshooting, and the successful deployment of a secure, live production environment.

### **Core Engineering Implementation**
* **Data Architecture:** Utilized **Firebase Firestore** (NoSQL) to collate unstructured community data, ensuring real-time synchronization.
* **Cloud Security:** Engineered server-side security rules to protect the database from unauthorized modification while maintaining public access for data submission.
* **Performance Optimization:** Developed using a lightweight frontend stack (HTML5/CSS3/ES6 JavaScript) for cross-device compatibility.
* **API Management:** Managed Google Cloud Platform (GCP) credentials with strict domain-level restrictions to ensure project security.

---

## 🚀 Features
* **Real-time Lore Submission:** Instantly share insights categorized by Archon Quests, World Quests, or Character Lore.
* **Community Feed:** A live-updating archive of all traveler-submitted data.
* **Secure Backend:** Powered by Firebase Firestore with strict security rules to protect community data.
* **Responsive UI:** Designed to be accessible on both desktop and mobile devices.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6)
* **Database:** Google Firebase Firestore
* **Security:** Google Cloud API Restrictions & Firestore Security Rules
* **Hosting:** GitHub Pages

## 🛡️ Security Implementation
To ensure the integrity of the lore database, this project implements:
1.  **Domain Locking:** API keys are restricted to only function on the authorized domain.
2.  **Firestore Rules:** Granular permissions that allow public reading and creating, but strictly prohibit unauthorized editing or deletion.

## 📂 Project Structure
* `index.html` - The main entry point and UI.
* `style.css` - Custom styling and mobile-responsive layouts.
* `/assets` - Images and icons used in the terminal.
